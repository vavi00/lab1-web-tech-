# README

## Лабораторна робота №2

### Розробка REST API з FastAPI та взаємодія з фронтендом

### Мета роботи

Розробити бекенд-частину вебзастосунку з використанням **FastAPI**, що надає REST API для роботи з бібліотекою книг, та забезпечити взаємодію з готовим фронтендом (HTML, CSS, JavaScript).

---

### Структура проєкту

```
project-root/
│
├── backend/
│   ├── app/
│   │   ├── routers/
│   │   │   └── items.py
│   │   ├── database.py
│   │   ├── main.py
│   │   ├── models.py
│   │   └── schemas.py
│   └── __init__.py
│
├── public/
│   ├── index.html
│   └── styles.css
|   ├── src/
│     └── app.js
│
│
└── venv/
```

---

### Функціональність

* Отримання списку книг з бази даних
* Додавання нової книги
* Видалення книги
* Фільтрація книг за жанром
* Сортування таблиці за роком та рейтингом
* Динамічне оновлення таблиці без перезавантаження сторінки

---

### Використані технології

* **FastAPI** — бекенд, REST API
* **SQLAlchemy** — ORM для роботи з БД
* **SQLite** — база даних
* **HTML / CSS / JavaScript** — фронтенд
* **Uvicorn** — ASGI сервер

---

### Запуск проєкту

1. Активувати віртуальне середовище:

```bash
venv\Scripts\activate
```

2. Перейти до папки бекенду:

```bash
cd project-root/backend
```

3. Запустити сервер:

```bash
uvicorn app.main:app --reload
```

4. Відкрити у браузері:

```
http://127.0.0.1:8000
```

---

### Висновок

У ході виконання лабораторної роботи було реалізовано повноцінний REST API та забезпечено його коректну взаємодію з фронтендом. Отримано практичні навички роботи з FastAPI, SQLAlchemy та організації структури вебпроєкту.
